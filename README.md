# fulcrumfoundry.github.io

Org-level GitHub Pages site for the fulcrumfoundry organization.

Live at: https://fulcrumfoundry.github.io/

## Apps hosted here

- `/30a/` - 30A travel guide for Seagrove Beach (mirrored from `30a-guide` repo)

## Notes

- `.nojekyll` keeps GitHub Pages from running Jekyll, so files serve as-is.
- Repos named `<org>.github.io` are auto-enabled for Pages on the default branch. No manual config required.
